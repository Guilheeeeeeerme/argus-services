# Triage Client UX Refactoring Plan

## Scope

This plan covers the Triage Client app at `argus-services/triage/client/`.

## Changes Made

### 1. Shared Library Integration
- Added `@argus/ui` workspace dependency
- Imported tokens and global CSS
- Wrapped app in `<ThemeProvider>`

### 2. Component Extraction
- `TriageWorkspace.tsx` — main workspace with decision feed
- `DecisionDetail.tsx` — decision detail with evidence list and resolve form

### 3. Shared API Layer
- `api.ts` — extracted fetch wrapper, WebSocket config, and types

### 4. Theme Support
- Light/dark mode via ThemeToggle in header
- System preference detection
- localStorage persistence

### 5. Responsive Grid
- Two-column layout (1fr 1fr)
- Collapses to single column at 700px breakpoint
